[id="renaming-a-bookmark\_\{context\}"]

You can rename a bookmark to distinguish it from other bookmarks. If you have bookmarks to several folders that all share the same name, you can tell the bookmarks apart if you rename them.

Renaming the bookmark does not rename the folder.

Procedure

\begin{enumerate}
\item Right-click the bookmark in the side bar.
\item Select \textit{Rename…}.
<!-- image -->
\item In the \textit{Name} field, enter the new name for the bookmark.
<!-- image -->
\item Click btn:[Rename].
\end{enumerate}

Verification

\begin{itemize}
\item Check that the side bar lists the bookmark under the new name.
<!-- image -->
\end{itemize}
